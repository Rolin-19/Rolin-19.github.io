01 Tentang

Yogyakarta, Indonesia.

Saya mulai bekerja tahun 2021, saat masih menempuh D1 Ground Handling di Sekolah Tinggi Teknologi Kedirgantaraan. Dari situ saya terbiasa dengan aturan ketat soal waktu dan keselamatan. Saya magang di layanan penumpang PT Gapura Angkasa, lalu menjadi train attendant di PT Reska Multi Usaha.

Di ritel saya berhadapan langsung dengan angka. Sebagai Assistant Chief of Store di Lawson Indonesia, saya menyusun jadwal shift untuk tujuh kru dan menulis laporan penjualan harian. Laporan itu dipakai untuk menentukan produk mana yang perlu ditambah stoknya. Kebiasaan mencatat itu saya bawa ke Miniso dan Cinema XXI.

Sekarang saya mengarahkan fokus ke analisis data. Saya menyelesaikan kursus Python dan SQL, lalu mengerjakan proyek latihan: analisis data konservasi empat taman nasional, program rekomendasi film, pencari rekomendasi kuliner, dan segmentasi transaksi bank dengan machine learning. Semuanya saya dokumentasikan supaya bisa diperiksa.

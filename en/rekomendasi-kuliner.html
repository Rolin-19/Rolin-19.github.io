Indonesian Food Recommendation

A practice program that searches for food by type and budget, available in two versions: terminal and web. Name a type of food and the budget you have, and the program finds what fits and sorts it from the cheapest.

Where the project came from

The code started as an exercise on Codecademy, and then I developed it on my own. At first the food data was written directly in the code. I moved it into a data_kuliner.json file so that prices can be changed, added, or removed from inside the program without touching the code.

The program is not a big application. It is a warung notebook for my own use, and I deliberately wrote it that way so it does not sound bigger than it really is.

Two versions of the program

The program can be used in two ways. The terminal version runs through the kuliner.py file; from there the data can be searched and also added, changed, or removed. The web version is a single HTML page that reads data_kuliner.json and presents it as a search and filter view. The web version only displays data, while changes are still made through the terminal version.

Features

  • Search by type and budget. Pick a type (makanan, minuman, or camilan), then enter the maximum price. The remaining budget shows on every item.
  • A saver label for items priced at half the budget or less.
  • Search by name, region, or warung name. For example, type Jogja or Bu Tini.
  • Value set: finds a combination of one food and one drink with a total as close as possible to the budget without going over it. If there is money left, the cheapest snack is added as well.
  • Similar recommendations from the item currently selected, preferring the same region and sorted by the closest price.
  • Manage the data (terminal version): add a new item, change a price, or delete one. Changes are saved straight to the JSON file.

Data

The initial data holds 35 items: 15 foods, 10 drinks, and 10 snacks. Each item stores a name, category, price per portion, region of origin, place name, and a free note. The place and note fields are deliberately left empty so they can be filled in from the data management menu. That way the records are genuinely adjustable, for example the price at a regular warung, not a rough guess.

On the prices, I did not make up the numbers. They follow two sources: geokepo.id's 2026 guide to Indonesian food prices and the 2026 Warung Guide from The Indonesia Guide. From them I took the ranges for street snacks, street meals, warungs, nasi goreng, coffee, and iced tea. Both are general guides, so the figures are estimates, not a fixed benchmark at every warung. The links were accessed on 17 October 2026.

What this project practises

  • Data structures: storing and retrieving food data from a form that is easy to change.
  • Search and sorting algorithms: filtering by budget, sorting from the cheapest, and assembling value-set combinations.
  • Handling JSON files, including writing changes back to the original file.
  • Unit testing to make sure the logic does not break when data is added.
  • Git to record every code change.

Biodiversity in National Parks

A National Park Service data analysis of the conservation status of species across four American national parks. Of 5,541 unique species, 179 are recorded with a conservation status other than No Intervention.

Questions to answer

There are two questions. First, which species category holds the most protected species. Second, which category has the highest proportion relative to the number of species in its own category. I answered them separately because the results are not the same. These questions shape what follows, from cleaning the data to choosing which test is worth running.

One term needs defining first. What I call protected here is a row whose conservation_status column is not No Intervention. That covers Species of Concern, Endangered, Threatened, and In Recovery. These are categories in the National Park Service data, not a legal protection status.

Data used

The data comes from the National Park Service and serves as practice material. There are two files that complement each other.

File Rows Contents
species_info.csv 5,824 Category, scientific name, common name, conservation status
observations.csv 23,296 Number of species occurrences in four parks over seven days

The four parks recorded: Yellowstone, Yosemite, Bryce, and Great Smoky Mountains.

One thing needs fixing first. The species_info.csv file holds 5,824 rows, but only 5,541 unique scientific names. So there are 283 extra rows from 274 scientific names that appear more than once. The rule I used to pick rows: if one scientific name has more than one status, I keep the row whose status is not No Intervention. If every row is No Intervention, I take the first row. I keep the row order stable so the result is the same every time the program runs. Because the questions are about species, the analysis uses the cleaned version.

How I worked

  1. Loading both CSV files, then checking the data structure with shape, info, and describe.
  2. Filling the empty conservation_status column with No Intervention.
  3. Dropping the extra rows so one scientific name is represented by one row.
  4. Calculating the proportion of protected species for each category.
  5. Testing whether species category relates to conservation status with a permutation test.
  6. Comparing total observations across the national parks.

Results

Of the 5,541 species, 179 are protected. That is only 3.23%. The rest fall into the no special intervention category.

The answer depends on how you read it. Counted by number, birds lead with 75 species. Counted by proportion within their own category, mammals rank highest with 30 of 176 species, or 17.0%.

Hypothesis test

The next step tests whether species category relates to conservation status. The chi-square test was the first choice, but its result revealed a problem: 23 of 35 expected cells below 5. The usual rule is that at least 80% of cells must hold a value of 5 or more, so this test is not suitable here.

I switched to a permutation test with 10,000 runs. This test does not require the expected-value condition above.

591.15chi² value
23 of 35expected cells below 5
< 0.0001p-value from the permutation test

The p-value is far below 0.05. If species category truly had no relationship with conservation status, the chance of a pattern like this appearing would be very small. So in the data I used, species category and conservation status are indeed related. One note: this test shows a relationship, not cause and effect.

Limitations

This data covers only four parks and seven days of observation, so the results describe those four parks alone, not the whole United States. The observation counts also record how many times a species appeared, not how many individuals there were. Both points are worth keeping in mind before drawing a wider conclusion.

# Portfolio Website

Situs portofolio pribadi Rolin Stallin — dibangun sebagai bagian dari proyek
*Portfolio Website* di Codecademy.

Halaman ini ditulis dengan HTML dan CSS saja: tanpa kerangka kerja, tanpa
JavaScript, tanpa pemanggilan ke server luar. Semua huruf memakai huruf bawaan
sistem (Georgia + Segoe UI), jadi halaman tetap tampil sama walau dibuka
sepenuhnya tanpa koneksi internet.

## Isi

| Bagian | Keterangan |
| --- | --- |
| 01 Tentang | Latar belakang singkat dan daftar alat yang dipakai |
| 02 Proyek | Proyek *Biodiversity in National Parks* beserta temuan utama |
| 03 Cara saya bekerja | Empat langkah yang saya pakai saat mengerjakan analisis |
| 04 Kontak | Email dan repositori GitHub |

## Struktur berkas

```
index.html            halaman utama
css/style.css         seluruh tampilan (satu berkas, ada komentar penanda bagian)
assets/chart1.png     grafik proporsi spesies dilindungi per kategori
assets/chart2.png     grafik total observasi per taman nasional
assets/foto/*.jpg     foto taman nasional (sumber: Wikimedia Commons)
```

## Melihat di komputer sendiri

Buka berkas `index.html` dengan peramban (klik dua kali). Tidak perlu memasang
apa pun.

## Catatan tampilan

Palet warna diambil dari foto taman nasional yang dipakai di halaman:
hijau hutan `#1F3D2B`, krem `#F6F2E9`, dan bata `#B5561F`. Tampilannya dibuat
seperti halaman cetak — judul memakai huruf serif, pemisah antar bagian memakai
garis tipis alih-alih kotak dan bayangan. Tidak ada gradien warna.
